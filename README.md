# Nacho vs Geneva

A roguelike shooter for the browser. Nacho, one brave tortilla chip, fights corporate ghouls, trams and buses across six far-too-clean Geneva districts, picking up food and music upgrades and facing six of seven bosses in a random order.

**Play:** https://sam-w-jones.github.io/Nacho-v-Geneve/

Works on desktop (WASD, mouse, Space to dash) and phones (thumb sticks with auto-aim; best played sideways). The whole game is the single `index.html` file.
